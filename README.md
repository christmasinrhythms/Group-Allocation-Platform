# Group Allocation Platform

[Open the workbench](https://christmasinrhythms.github.io/Group-Allocation-Platform/)

Import an existing grouping workbook once to create the working roster. It needs an `Assignments` sheet with roster IDs in column A, game groups in F, and tables in G, plus an `Overview` sheet listing game groups in A7:B18. An optional `Previous Seating` sheet stores roster IDs and last year's tables in columns A and B.

The workbench saves moves and swaps in this browser. **Save arrangements** confirms the browser copy. **Export Excel** downloads a new workbook containing the current arrangements and its original workbook layout. Import an exported file on another browser to continue from that snapshot.

The site uses browser storage for the roster. The repository contains application code and fictional demo data. The current roster and exported workbooks stay in the browser or in downloaded files.
